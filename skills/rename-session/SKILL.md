# 日本語セッション名

会話の主題を日本語1〜2文に要約する。ローカルの LM Studio (`http://localhost:1234`) が利用できる場合に `/v1/models` のモデルで `/v1/chat/completions` を呼び、15字以内・体言止めのタイトルを生成する。JSON は Python 等の encoder で作り、要約をシェルコードへ直接埋め込まない。接続・応答エラーを確認し、未起動ならその旨を伝える。ユーザーが別の方法を選ぶまではクラウドへ送らない。

生成したタイトルを提示する。ホストにセッション名変更機能があればその正規の操作を案内する（Claude Code は `/rename <タイトル>`）。機能がなければ候補の提示まで。アプリ内部のセッションファイルは編集しない。
